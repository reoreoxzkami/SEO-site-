制作方針

主要キーワード、関連語、ユーザー課題、解決策、信頼要素を1ページ内で自然に説明し、検索エンジンに内容が伝わるページを目指します。

  1. 本番ドメインにcanonicalとサイトマップURLを変更
  2. Cloudflare PagesにGitリポジトリを接続
  3. 独自ドメイン、HTTPS、リダイレクトを確認
  4. Search Consoleにサイトマップを送信

Cloudflare Pages向けの公開準備済み

wrangler.toml、_headers、_redirects、robots.txt、sitemap.xmlを用意しています。公開前にexample.comを実ドメインへ置き換えてください。

よくある質問

Cloudflare PagesはSEOに向いていますか？

静的HTMLをCDNで高速配信できるため、表示速度を高めやすくSEO施策の土台に向いています。

公開前に必ず変更する項目は？

canonical、OGP URL、robots.txt、sitemap.xml、_redirects内のドメインを本番ドメインへ変更してください。
